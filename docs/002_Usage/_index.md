## 基本操作

### 機器の配置
1. 右側の機器リストから機器を選択
2. キャンバスにドラッグ&ドロップ
3. 配置された機器をドラッグして位置を調整

### 接続の作成
1. 機器のポートからドラッグを開始
2. 接続先の機器のポートにドロップ
3. 自動的にエッジが作成される

### 機器設定の変更
#### クイック設定（クリック）
- ノードをクリックして局番を変更
- Class（A/B）バッジをクリックして切り替え
- 速度（100M/1G）バッジをクリックして切り替え

#### 詳細設定（右クリック）
- ノードを右クリック
- コンテキストメニューから「パラメータ設定」を選択
- ダイアログで詳細設定を変更

### 構成の検証
1. チェックボタン（🔍）をクリック
2. 検証結果が右側のパネルに表示される
3. エラーがある場合は詳細を確認
4. 問題を修正して再度チェック

### データの保存
- **エクスポート:** Export JSONボタンをクリック
- **インポート:** Import JSONボタンからファイルを選択

## 応用機能

### 自動配線
機器を局番順に自動的に接続します。

#### 使い方
1. 機器を配置
2. 局番を設定（自動採番も可能）
3. 自動配線ボタンをクリック
4. 確認ダイアログで「実行」をクリック

#### 注意事項
- 既存の接続はすべて削除されます
- マスタ局が必要です

---

### 自動配列
バラバラに配置された機器をきれいに整列します。

#### 使い方
1. 自動配列ボタンをクリック
2. ネットワークトポロジーを自動検出
3. 検出されたトポロジーに応じて自動的に整列される

#### トポロジーの自動検出
ネットワーク構成を分析し、以下のいずれかのトポロジーを自動判定します：

- **LINE（ライン型）**: マスタ局から一直線に接続
- **STAR（スター型）**: 中央のスイッチから複数の機器に分岐
- **RING（リング型）**: すべての機器が環状に接続
- **MIXED（混合型）**: 上記以外の複雑な構成

検出されたトポロジーに最適なレイアウトが自動的に適用されます。

### CSP機器の読み込み
CSP+ファイルから機器情報を自動的に読み込み、パレットに追加します。

#### 手順
1. CSP+ ZIPファイルを `tools/csp_raw/` に配置
   - `tools/csp_raw/` は CSP+ ZIP/BMP などの元データ置き場で、Git管理対象外です。
2. 以下のコマンドを順に実行：
   ```bash
   npm run build:csp
   npm run sync:csp
   npm run build:device-defaults
   ```
3. 機器リストに新しい機器が表示される

---

### デフォルト値のカスタマイズ
CSVファイルを編集することで、機器のデフォルト設定をカスタマイズできます。

#### 手順
1. 機器デフォルト値一覧（`public/data/device-defaults.csv`）を編集
   - Class
   - 速度
   - ポート数
   - カテゴリ
2. 以下のコマンドを実行：
   ```bash
   npm run build:device-defaults
   ```
3. `public/data/device-defaults.json` と `src/data/device-defaults.json` が生成され、変更が反映される

#### 編集可能な項目
- `classDefault`: デフォルトのClass（A/B）
- `classOptions`: 選択可能なClass
- `speedOptions`: 対応速度（100M/1G）
- `category`: 機器のカテゴリ
- `deviceTypeDetailNormalized`: 機器種別
