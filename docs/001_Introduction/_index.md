## 概要

CC-Link IE TSNのネットワーク構成を直感的に作成・検証できるWebツールです。

ドラッグ&ドロップで機器を配置し、接続を作成するだけで、複雑なネットワーク構成のチェックが可能になります。

## 技術スタック

- **フレームワーク:** React 18
- **言語:** TypeScript
- **UI:** Material-UI 6 + Emotion
- **フローチャート:** react-flow 11
- **状態管理:** Zustand
- **ビルドツール:** Vite
- **テスト:** Playwright
