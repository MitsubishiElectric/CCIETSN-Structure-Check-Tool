## 検証機能の詳細

### 【全マスタ共通】

全29機種で以下の検証が実行されます。

#### 1. 基本構造チェック
- **マスタ局存在チェック**: ネットワークにマスタ局が存在するか検証
- **最大接続局数チェック**: 機種ごとの最大接続台数を超えていないか検証

#### 2. 接続可否表チェック
- **速度組み合わせ検証**: 1G↔100M等の速度組み合わせが接続可能か検証
- **デバイス種別組み合わせ検証**: マスタ、ローカル、リモート、Ethernet機器の組み合わせ検証
- **スイッチ種別チェック**: Class B対応/Class A対応/一般スイッチの使用可否を検証
- **条件付き許可の検証**: 通信周期設定等の条件が満たされているか検証

{{% alert title="実装の仕組み" color="primary" %}}
- Connection Table有りの機種: JSONテーブルから詳細な接続可否を判定
- Connection Table無しの機種: ハードコードされた基本表（8パターン）で判定

いずれの場合も`src/services/rules/connectionTableRule.ts`により検証されます。
{{% /alert %}}

#### 3. トポロジ制約
- **BA混在時リング禁止**: Class B/A混在ネットワークではリング接続不可
- **スイッチ+リング制約**: リング構成で産業用スイッチ使用不可（スイッチのみ構成は可）

#### 4. スイッチ境界制約
- **BA境界スイッチ制約** (`baBoundarySwitchRule.ts`)
  - BA混在時、マスタ側にClass Bスイッチがあれば境界スイッチもClass B必須
  
- **スイッチ境界サイクリックデータ制約** (`switchBoundaryCyclicDataRule.ts`)
  - スイッチ境界でのデータサイズ制限

---

### 【RJ71GN11-T2 & MXコントローラ専用】

以下の10機種で追加検証が実行されます:
- RJ71GN11-T2
- MXR300-16/32/64, MXR500-128/256
- MXF100-8-N32/P32, MXF100-16-N32/P32

#### 5. 速度境界制約
**1G↔100M境界サイクリックデータサイズ制約** (`checkCyclicDataSizeConstraint`)

- **制約内容**: 100M側のClass B機器すべてのサイクリックデータサイズ合計が2048B以下
- **適用条件**: マスタが1G、かつ100M機器との境界が存在する場合
- **実装場所**: `src/services/rules/index.ts`

#### 6. プロトコルバージョン制約
**BA混在時のプロトコルバージョン1.0制約** (`checkProtocolVersionConstraint`)

BA混在モードでプロトコルバージョン1.0の機器が存在する場合、以下の制約が適用されます。

##### パターン1: Class Bのみに1.0が存在する場合

**制約:**
- BA境界のClass A側サイクリックデータサイズが2048B以下

**計算式:**
```
合計サイズ = 256B(基本) + 146B×ローカル台数 + 106B×リモート台数 + カスタムデータサイズ合計
```

##### パターン2: Class Aに1.0が存在する場合

**制約1: ホップ数制限**
- マスタの各ポートから終端までのClass B機器（スイッチ含む）が8台以下

**制約2: データサイズ制限**
- BA境界のClass A側サイクリックデータサイズが2048B以下（パターン1と同じ）

{{% alert title="注意" color="warning" %}}
プロトコルバージョンが未設定の機器がある場合、この制約は適用されません。
{{% /alert %}}

**実装場所**: `src/services/rules/index.ts`

#### 7. マルチキャスト関連制約
**マルチキャストスイッチポート制約** (`multicastSwitchPortRule`)

- **制約内容**: マルチキャストモード時のスイッチポート設定が適切か検証
- **実装場所**: `src/services/rules/multicastSwitchPortRule.ts`

---

### 【MXコントローラ共通制約】

以下の9機種で共通制約が適用されます:
- MXR300-16/32/64, MXR500-128/256
- MXF100-8-N32/P32, MXF100-16-N32/P32

#### 8. マルチキャストモード禁止
- **制約内容**: MXコントローラはマルチキャストモードに対応していません
- **検証タイミング**: 通信モード選択時に即座にエラー

#### 9. リング構成禁止
- **制約内容**: MXコントローラはリング構成に対応していません
- **検証タイミング**: ネットワークにループが検出された場合に即座にエラー
- **例外**: スイッチのみで構成されたリングは使用可能

#### 10. ローカル局禁止
- **制約内容**: MXコントローラはローカル局を接続できません
- **検証タイミング**: 接続可否表チェック時

**実装場所**: `src/services/rules/index.ts`, 接続テーブルJSON

---

### 【MXRシリーズ専用】

以下の5機種でMXR固有制約が適用されます:
- MXR300-16/32/64, MXR500-128/256

#### 11. 121局以上ライン接続制約
**121局以上ライン接続対応チェック** (`checkMXR121StationsLimit`)

- **制約内容**: MXRの同一ポートで121局以上接続する場合、対応デバイスのみ接続可能
- **対応条件**: ファームウェアバージョンが指定値以上の機器のみ
- **警告表示**: AC servo (MR-J5シリーズ) はF0以上が必要
- **実装場所**: `src/services/rules/mxr121StationsRule.ts`

{{% alert title="MXFの最大局数" color="info" %}}
MXFモデルは最大39局または47局のため、121局制限は適用されません。
{{% /alert %}}
